# RIDGELINE

山間の舗装サーキット Pine Ridge を走る PBR レースゲームです。5 台の AI と約 780 m のコースを 3 周し、順位とラップタイムを競います。

車両は 90 Hz の固定ステップで更新します。速度に応じた操舵、タイヤのグリップ限界、路肩でのグリップ低下、空気抵抗、6 速の自動変速、車両同士やガードレールとの接触をモデル化しています。追従、ボンネット、遠距離追従の 3 視点で走れます。

## 起動

Windows のリポジトリルートから実行します。初回構成には `build\generate_msvc2026-debug.bat` を使います。

```powershell
cmd /c build\build_msvc2026-debug.bat
Push-Location game\racing
..\..\build\msvc2026-debug\sinen.exe
Pop-Location
```

## 操作

SDL が認識した最初のゲームパッドを自動で使います。起動後に接続した場合も認識します。Xbox 配列での操作は以下のとおりです。

| 操作 | ゲームパッド | キーボード |
| --- | --- | --- |
| 開始・再開・再レース | A | Enter |
| ステアリング | 左スティック / 十字キー | A・D / ←・→ |
| アクセル | RT | W / ↑ |
| ブレーキ・停止付近から後退 | LT | S / ↓ |
| 視点切替 | X | C |
| コースに復帰 | Y | R |
| ポーズ | Start | Esc |
| メニューから終了 | B | Q |

## アセット

アスファルトと芝生のベースカラー、法線、AO・粗さ・金属度にミップマップ付き KTX2 を使用します。HDRI は背景と環境照明の反射に使用します。出典とライセンスは [アセットライセンス一覧](ASSET_LICENSES.md) を参照してください。
