# FFT Ocean

Examples の **Graphics → FFT Ocean** で起動します。
`ocean` と `shader_compiler` プラグインを実行時のカレントディレクトリに配置してください。

- P: Phillips / JONSWAP の風浪を切り替え
- S: 独立した長周期うねりを切り替え
- Space: 時間を停止・再開
- 上下: カメラの高さ
- Esc: Graphics メニューへ戻る

シミュレーション設定と API は [Ocean プラグイン](../../../plugins/ocean/README.md) を参照してください。
